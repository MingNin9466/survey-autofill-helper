# 问卷填表助手

**别再重复敲同一套答案。** 把自己的答案存成模板，一键填入问卷星、腾讯问卷、WPS 表单等国内主流问卷。

> 只做一件事：**只填不交**。脚本永远不会点“提交”，交卷前你都能逐题核对。

## 为什么做这个

问卷星、腾讯问卷、WPS 表单、金数据……每家的页面结构都不一样，所以“自动填表”脚本通常换一个平台就失效。这个脚本把两件事拆开：

- **模板引擎**：题干关键词 → 答案，匹配时忽略题号、标点、“（单选）”这类标注；
- **平台适配器**：问卷星 / 腾讯问卷 / WPS 表单各写一套解析，其他站点走通用识别兜底。

典型场景：课程问卷、志愿报名、社团登记、每周周报——同一类表单反复填，答案抄来抄去。存一次模板，以后一键完成。

## 功能

- **多套模板**：按问卷切换，规则可增删改，支持导出 / 导入 JSON。
- **抓题建模板**：列出识别到的每道题、题型、选项，逐题写答案后一键存成模板。
- **逐题反馈**：绿框=成功、红框=失败、灰框=跳过，每道题都有原因。
- **只填空白题**：不覆盖你已经手填的内容。
- **随机答案**：`随机` / `随机2`，多选题随机勾选。
- **纯本地**：不联网、不上传，模板存在篡改猴存储里。

| 平台 | 状态 | 说明 |
| --- | --- | --- |
| 问卷星（`wjx.cn` / `wjx.top` / `sojump.com`） | ✅ 已实测 | 单选 / 多选 / 填空 / 下拉，30 题真实问卷 |
| 腾讯问卷（`wj.qq.com`） | ✅ 已实测 | 单选 / 多选 / 填空，真实问卷 |
| WPS 表单（`f.wps.cn`） | ✅ 已实测 | 单选 / 多选 / 填空 / antd 下拉 |

矩阵题、排序题、文件上传、日期题、省/市/区题不猜答案，会明确标“请手动填写”。

## 安装

1. 在 Edge / Chrome 安装 [篡改猴 Tampermonkey](https://www.tampermonkey.net/)；
2. 安装脚本：把 `survey-autofill-helper.user.js` 拖进浏览器窗口，或打开下面的原始文件点「安装」：

```
https://raw.githubusercontent.com/MingNin9466/survey-autofill-helper/main/survey-autofill-helper.user.js
```

3. 打开问卷页并刷新一次，右下角出现蓝色「填」按钮。

> **国内网络**：`raw.githubusercontent.com` 经常超时，安装/更新请用镜像地址：
> `https://gh-proxy.com/https://raw.githubusercontent.com/MingNin9466/survey-autofill-helper/main/survey-autofill-helper.user.js`

## 快速上手

1. 打开问卷的**填写页**（不是编辑页 / 预览页）；
2. 点「填」→「抓题」，脚本会列出所有题目、题型和选项；
3. 在每题下面写答案，点「存为新模板」；
4. 以后遇到同类问卷：「填充」→「一键填充」，核对后自己点提交。

![抓题并保存为模板](docs/screenshots/scan.png)

## 答案写法

| 写法 | 含义 |
| --- | --- |
| `男` | 按选项文字匹配（忽略 `A.` 前缀、标点、空格） |
| `A` / `#2` | 按选项字母 / 第几个选项 |
| `随机` | 随机选一项 |
| `随机2` | 多选随机选 2 项 |
| `音乐\|运动` | 多选，多个答案用 `\|`（也支持逗号、顿号） |
| `暂无` | 填空题直接写入这段文字 |
| 关键词填 `性别\|身份` | 多个关键词命中任一即可 |

匹配时会归一化题干：去掉题号、`（单选）`、`（必填）`、标点和空格，所以问卷小改措辞也不用重做模板。

## 工作原理

```
问卷页面
   │
   ├─ 适配器（wjx / qq / wps / 通用） → [{ 题干, 题型, 选项, 输入框 }]
   ├─ 模板规则                        → 关键词归一化匹配
   └─ 填充引擎                        → 点 label / 写 value，再回读校验
```

- 适配器只读页面 DOM，不调用任何私有接口；
- 点击后会回读控件状态，显示“成功”就代表选项真的选中了；
- 面板放在 Shadow DOM 里，按键、粘贴、右键事件在面板边界截停，站点级拦截（比如问卷星吞 Backspace）影响不到面板输入框。

## 常见问题

**右下角没有「填」按钮？**
装完脚本要刷新页面。仍没有就按 `F12` 看 Console 是否有 `[问卷填表助手] v1.0.2 已加载`；没有这行说明域名没匹配或脚本被禁用。

**面板里输入框删不掉字？**
v1.0.1 已修复（问卷星在 `document` 上拦 Backspace，影子 DOM 又重定向了事件 target）。确认版本 ≥ 1.0.1。

**WPS 表单提示需要登录？**
WPS 表单通常要求登录 WPS 账号；未登录时输入框全是禁用状态。登录后再填充。

**表单显示“已达上限 / 停止收集”？**
发布者在后台关闭了收集或名额已满，**任何人都提交不了**，脚本不会也不应该绕过。

**题目被标“请手动填写”？**
矩阵题、排序题、文件上传、日期题、地区题属于有意不自动化。

**长问卷 / 分页问卷？**
长问卷先滚到底再点「重新识别」；分页问卷填完当前页点「下一页」，再点一次填充。

## 已知限制

- 永不自动提交——这是设计原则；
- 矩阵 / 排序 / 上传 / 日期 / 地区题需要手动；
- 收集上限、登录墙不在解决范围内；
- 平台改版可能导致适配器失效，欢迎带页面链接提 issue。

## 隐私与安全

- 不发起任何网络请求，不统计、不上传；
- 所有模板存在本机篡改猴的 `GM_setValue` 里；
- 仅供自己填问卷提速，请勿用于伪造问卷数据或绕过收集限制。
